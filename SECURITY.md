# Security

beer-text runs in the browser with no dependencies, no network requests and no HTML parsing: the heading's text only ever goes into the page as text, and color options are accepted only when they are real CSS colors.

## Reporting a problem

Please report a vulnerability privately through GitHub: the repository's **Security** tab, then **Report a vulnerability**. Don't open a public issue for it. Expect a first reply within a week.

## Supported versions

The latest published version gets fixes.
